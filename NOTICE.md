# Provenance and third-party components

This repository contains original adapter code and documentation. It also
contains short literal compatibility fingerprints that identify required seams
in a locally installed runtime.

The repository does not include copies of OpenAI packages, source files,
binaries, desktop application assets, or generated overlays. At runtime, the
adapter reads components supplied by the user's own ChatGPT macOS installation
and generates a local overlay on that machine.

OpenAI, ChatGPT, Codex, `@oai/*` package names, and related product names belong
to their respective owners. This project is not affiliated with or endorsed by
OpenAI. No license grant for third-party components is made by this repository.
